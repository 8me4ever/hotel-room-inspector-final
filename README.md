# 酒店客房 AI 辅助查房 Demo

课题：保洁完成后，通过房间照片发现可见问题，标出位置，并由人工复核是否达到可交付入住标准。

这是已验收功能的精简提交版。入口为手机网页，电脑运行后台，无需把电脑带进客房。包含上传、标准取景归位、AI逐项判断、问题定位、人工裁决、整改复查及模拟放房。

## 启动

需要 **Python 3.10 或以上版本**，仅使用标准库，**无需 pip、Node 或 npm**。

下载本仓库 ZIP 并解压，或执行：

```bash
git clone https://github.com/8me4ever/hotel-room-inspector-final.git
cd hotel-room-inspector-final
python server.py --port 8766
```

电脑打开 [http://127.0.0.1:8766/](http://127.0.0.1:8766/)。

Windows 也可以双击 `start.cmd`。保持后台窗口运行；端口已被其他服务占用时，可改用 `python server.py --port 8767`。

手机操作：电脑与手机连接同一 Wi-Fi，执行 `python server.py --port 8766 --lan`，或双击 `手机访问.cmd`。在电脑网页“我的 → 手机访问”查看地址和连接码，手机使用该局域网地址访问。

## 不配置 Key 也能体验完整流程

1. 分析方式选“离线 AI 观察”，点“一键载入六项生成样例”，开始检查。
2. 查看结果和原图。浴巾规格保持未知，因为照片不能证明实际规格。
3. 在“人工裁决与记录”填写核查人，选择结论并写明依据。本项目无真实酒店现场，演示规格确认时请选择“仅演示假设”。
4. 提交主管复核，查看原图并完成床品、台盆的独立复查，填写具体依据。
5. 模拟核实异味、布草更换、设备用水和消毒四项，勾选演示确认，再点击“模拟人工确认放房”。
6. 需要展示明确缺陷时，从“体验完整流程案例”选择“床品细节发现问题”，查看定位并进入整改复查。整改批次不继承旧通过结果。

上传测试图在 `assets/` 中。“体验乱序生成图”可展示自动归位；单项或整组替换、清空及换房自动清图均可使用。换房与清空只影响当前草稿，不删除已保存记录。

## 使用真实 AI

在启动服务的**电脑网页**进入“我的 → 视觉模型连接”，填写自己的连接：

```text
Base URL：https://api.deepseek.com
模型：deepseek-flash
API Key：仅在本机页面填写
```

以上为本项目已实测的 DeepSeek 配置。保存后，可用一张内置生成图验证；**验证、实时归位及实时检查均会发出实际请求**，按服务商规则使用额度。手机端不配置密钥。

上传区分析方式选“实时 AI”，再添加图片。API 请求失败会明确报错，不会自动套用离线结果。离线只匹配已有原始素材，新图或转存图应使用实时模式。

Windows 可选择“记住本机”；换电脑需自行配置。仓库不含 API Key、运行数据库、手机配对凭据或原开发机配置。

## 真实与模拟边界

| 环节 | 实现 |
|---|---|
| 11张酒店样例图 | 全部由 ChatGPT 内置图片工具生成，无实拍 |
| 实时归位、卫生判断 | 调用配置的视觉模型；问题文字、照片和可选位置来自返回结果 |
| 离线 AI 观察 | 按原图哈希匹配已有观察，不是实时识别 |
| 预设流程 | 固定案例逻辑，不作为真实AI效果 |
| 覆盖校验、分流、复核门槛 | 程序规则 |
| 现场核查、实际清扫及放房 | 明确模拟，不证明真实酒店作业完成 |

## 检查和人工边界

- 六类取景：床铺全景、床品细节、地面床边、台盆台面、马桶、毛巾备品。
- 八项可见检查：床铺整理、床品污渍异物、垃圾遗留物、地面污渍、台盆台面、马桶表面、浴巾、牙具。
- 四项人工核实：异味、布草更换、设备用水、清洁消毒。
- 明确问题可直接整改；模糊项需人工裁决；缺图或质量不足需补拍。
- 即使AI通过，床品和台盆仍需独立复查。照片通过不等于整房合格，最终由人工确认。
- 人工裁决记录结论、具体问题、理由、核查人与修订。电脑“我的”可导出JSONL候选标注，**不会自动训练模型**。

## 整体思路
### 一、产品模式一定是手机端页面，更适配真实使用场景

员工在客房内操作，手机更适合拍摄、上传、查看原图和填写核查记录。电脑只提供后台服务，不需要携带进房间。

### 二、查房应该拆成哪些检查项？

当前 Demo 分为八项视觉检查和四项人工核实。

| 视觉检查项 | 主要检查内容 | 判断时需要注意 |
|---|---|---|
| 床铺整理 | 枕头、被子是否明显散乱，床面是否整理到位 | 正常细小褶皱不直接算问题 |
| 床品污渍与异物 | 可见污渍、毛发、异物 | 毛发与缝线、污渍与阴影可能混淆 |
| 可见垃圾与遗留物 | 已拍区域内的纸团、垃圾及遗留物 | 发现不明物品应按酒店流程处理，不能一律当垃圾丢弃 |
| 地面可见污渍 | 已拍地面的明显污迹 | 反光、地板纹理可能被误认 |
| 台盆与台面 | 盆内、排水口附近、台面的明显污渍、残留与杂物 | 天然石纹、水光和淡痕需要区分 |
| 马桶可见表面 | 座圈、内壁等可见表面的明显污渍 | 盖板未打开或有遮挡时不能判为干净 |
| 浴巾配置 | 可见数量是否符合房型配置，规格是否有依据 | 两件白色巾类不等于两条符合规格的浴巾 |
| 牙具配置 | 完整备品区内是否有足够数量的可辨识牙具 | 包装不明、被遮挡时不能推定齐全 |

四项人工核实为：异味、布草是否更换、设备及用水功能、清洁消毒流程是否完成。它们需要现场感知、实际操作或可追溯记录，不能只看照片勾选通过。

### 三、需要区分“照片能提供证据”和“AI能可靠下结论”。即使照片中有相关内容，也不意味着模型一定看得准。

**照片适合提供的证据**：包括明显污渍、可见垃圾、床面明显散乱，以及完整配置区内可辨识物品的数量。判断只适用于拍到且足够清楚的范围，不能从一张正常近照推断整张床、整个卫生间或整间房都合格。

**照片中有信息、但需要人工裁决的情况**：包括细线是毛发还是缝线，浅色痕迹是污渍还是纹理，深色区域是残留还是阴影。人工可以先查看完整原图；仍分不清时应补近照、换角度或现场核查，不能为了结束流程强行二选一。

**单靠照片无法证明的内容**包括：

- 房间有没有异味。
- 床单是否实际更换，而不是重新铺平。
- 清洁消毒操作是否按要求完成。
- 空调、插座、热水、排水等功能是否正常。
- 折叠巾类的真实尺寸、规格是否符合要求。
- 未入镜区域是否存在问题。

数量判断也有前提。例如，完整备品区清楚可见且只放了一套牙具，才有依据判断数量不足；照片只拍到半个台面，另一套牙具可能在画面之外，此时应判证据不足。

### 四、AI 放行与人工复核的分界线应该怎么划？

当前项目把“照片检查通过”和“客房最终放房”分开。AI 可以提出可见项目的判断，不能直接决定整间房可交付入住。

| AI结果或证据情况 | 应采取的动作 | 人工承担的责任 |
|---|---|---|
| 明确可见问题 | 标出问题位置，进入整改 | 不必先由主管逐条确认才允许清扫；如存在误报，可有依据地纠正 |
| 性质、身份或规格不确定 | 进入人工裁决 | 查看对应原图、补充依据，确认是问题、不是问题或仍无法判断 |
| 缺图、过暗、模糊、拍错目标 | 要求补拍 | 补齐有效证据，不能靠勾选把缺证据变成通过 |
| 可见项目未发现异常 | 形成照片检查通过或待人工确认状态 | 继续必要独立复查、现场核实和最终确认 |

人工参与有三个不同目的：裁决模糊项；独立复查 AI 可能漏掉的问题；核实照片无法证明的事项并最终确认放房。三者不能互相替代。

“明确问题可直接整改”省去的是整改前的一次重复确认，不是取消最终查房。AI 的明确判断也可能有误，因此仍应保留查看证据和人工纠正的路径。

只有必拍证据有效、未解决问题与未知项处理完、必要复查及现场事项记录完整后，才允许模拟人工确认放房。

未来是否减少某些项目的人工重复检查，应根据真实场景验证决定。不能因为模型自报“很有把握”，或连续几次判断通过，就直接开放自动放房。

### 五、 AI 漏检应该如何兜底？

最需要防范的情况是：房间有问题，但 AI 自信地判断通过。因此，不能只复核 AI 主动标出的疑点。

当前和后续应分别从以下层面处理：

1. **控制覆盖范围。** ：用六类必拍任务减少随手拍带来的遗漏。缺任务、拍错对象或照片不可用时，不形成该项通过结论；六张图齐全也不等于整房无盲区。
2. **控制证据质量。** ：对过暗、模糊、遮挡及内容不可辨的照片要求补拍。照片清晰只是必要条件，仍不能保证细小问题全部检出。
3. **对高风险区域独立复查。** ：当前床品和台盆即使 AI 判通过，也要求人工查看相关完整原图并填写复查依据。复查发现遗漏时，应新增问题或纠正结论，不能只勾“已看”。
4. **对非视觉项目保留人工核实。** ：布草更换、消毒、异味、设备功能不能被一张干净照片替代。
5. **对异常保留未知状态。** ：网络失败、模型报错或输出不完整，不得静默变成通过；应重试或转完整人工查房。
6. **对执行质量另做抽查。** ：系统能要求留记录，但不能证明人员认真看过照片。真实试点仍需要独立抽查、漏检复盘和人员执行评估。

### 六、这个项目存在的问题与思考

1. **仍无法实质确认该产品是否提效** ：对该产品目前状态来说，人工复查越完整，风险可能越低，但节省工时的空间也越小，必须用实测找平衡。
2. **全酒店房间的覆盖永远是难题** ：房间实际状态、照片拍到的内容、AI看出的内容是三件不同的事，任何一层都可能丢失信息。酒店环境是否整洁是影响客人入住体验极为重要的因素，依赖AI判定初期一定会引入人工实地复核，事实上短期内并没有减少工作量，反而加大了复核端的难度。整个产品仍需要长期的跟踪和反馈进行迭代优化，才能达到比较好的状态。
3. **细节场景AI模型的识别边界**： 对AI来说，识图的精准性取决于模型性能和图片质量，尤其是细小目标与正常外观容易混淆。毛发、线头、缝线、反光、石纹和淡痕，都可能导致误报或漏检；为了快速上传而降低图片质量，也可能损失关键细节。
4. **保洁人员在使用上的潜在问题**：通常来说，保洁人员普遍知识程度较低，对新产品的理解和领悟能力有所欠缺。一方面是要解决整个产品的简洁度和直观性，最优能让保洁人员以最简单最不需要理解的方式完成全流程的使用。另一方面是要解决保洁人员可能存在的投机取巧，将上一个房间的照片传到下一个房间中，使得这间房间本身并没有达到可交付的标准，但AI判定其已达到可交付标准而放房，出现不必要的纠纷问题。
